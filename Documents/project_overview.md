# Project Overview: LogiQuest

## Introduction
LogiQuest is an advanced interactive learning and interview platform built with cutting-edge technologies. It provides a robust environment for competitive programming and collaborative learning.

## Core Features
1. **Problem Solving System:** Supports various problem types (Coding, SQL, System Design) with advanced metadata and verification workflows.
2. **Competitive Coding (Arena):** Real-time contests with live leaderboards and announcements.
3. **Learning & Career:** Curated study plans, AI-simulated mock interviews, and gamified challenges.
4. **Community & Social:** Threaded discussions, blogs, private messaging, streaks, and badges.
5. **Real-Time Engine:** Powered by Socket.io and Redis for collaborative coding and chat.
6. **Code Execution:** Integrated Judge0 cloud engine supporting multiple languages (JS, Python, C++, Java, SQL).

## Architecture
- **Frontend:** Next.js 16 (App Router), React 19, Tailwind CSS 4, Framer Motion, Monaco Editor.
- **Backend:** Next.js Server Actions, custom Node.js Socket.io server.
- **Database:** PostgreSQL with Prisma ORM, Redis.
- **AI Suite:** Google Gemini (Pro/Flash) and Groq.
- **Infrastructure:** Docker, Vercel, GitHub Actions.
