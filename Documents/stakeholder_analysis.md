# Stakeholder Analysis

## 1. Primary Stakeholders (End Users)
- **Students / Learners:** Primary users of the platform to practice DSA, follow study plans, and view algorithm visualizations.
- **Competitive Programmers:** Users who participate in contests, track ratings, and solve advanced algorithmic challenges.
- **Job Candidates:** Individuals preparing for tech interviews via AI mock interviews and curated company-specific problem sets.

## 2. Secondary Stakeholders
- **Problem Setters / Contributors:** Users or admins who create new problems, write editorials, and verify solutions.
- **Interviewers / Mentors:** Professionals using the real-time collaboration features to conduct interviews or teach concepts.

## 3. Internal Stakeholders
- **Platform Admins:** Managing user accounts, contest scheduling, and moderating community discussions.
- **Development Team:** Software engineers, UI/UX designers, and QA testers responsible for building and maintaining LogiQuest.

## 4. External Stakeholders
- **API Providers (e.g., Judge0, Gemini, Groq, Cloudinary):** Third-party services the platform relies on for code execution, AI inference, and media hosting.
- **Hosting Providers (Vercel, AWS/GCP for DB):** Infrastructure providers ensuring high availability and performance.
