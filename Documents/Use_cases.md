# Use Cases

## Use Case 1: Solve a Coding Problem
- **Primary Actor:** Learner
- **Precondition:** User is logged in.
- **Flow:**
  1. User navigates to the problem list.
  2. User selects a problem and views the description.
  3. User writes a solution in the code editor.
  4. User clicks "Run Code" to test against sample test cases.
  5. User clicks "Submit" to test against hidden test cases.
  6. System evaluates the code and displays the verdict (AC, WA, etc.).

## Use Case 2: Participate in a Contest
- **Primary Actor:** Competitive Programmer
- **Precondition:** Contest is active, user is logged in.
- **Flow:**
  1. User registers for the active contest.
  2. Upon start, user views contest problems.
  3. User submits solutions.
  4. System updates the live leaderboard.
  5. Upon contest end, rating updates are calculated.

## Use Case 3: Take an AI Mock Interview
- **Primary Actor:** Job Candidate
- **Precondition:** User is logged in.
- **Flow:**
  1. User starts a new AI mock interview session.
  2. System provides a problem statement.
  3. User writes code and explains approach to the AI via chat.
  4. AI agent responds with hints, critiques, or follow-up questions.
  5. Session ends, and AI provides a comprehensive feedback report.
